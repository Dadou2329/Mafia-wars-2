MAFIA WARS II : Dadou vs Even — version Windows
===============================================

LANCER LE JEU
1. Téléchargez MafiaWars.exe (rien d'autre à installer ; si vous avez reçu une archive .zip,
   décompressez-la d'abord : clic droit > « Extraire tout… »).
2. Double-cliquez sur MafiaWars.exe.
   - Windows peut afficher « Windows a protégé votre ordinateur » : le programme n'est pas
     signé. Cliquez sur « Informations complémentaires » puis « Exécuter quand même ».
   - Le pare-feu peut demander l'autorisation : acceptez pour les « réseaux privés »
     (nécessaire pour jouer à deux sur le même réseau).
3. Une fenêtre noire (le serveur du jeu) s'ouvre, puis le jeu s'ouvre dans votre navigateur.
   Gardez la fenêtre noire ouverte pendant toute la partie : la fermer arrête le jeu.

JOUER À DEUX (même chacun chez soi)
Un seul joueur lance MafiaWars.exe : l'hôte. Son adversaire n'a RIEN à lancer.
1. L'hôte lance MafiaWars.exe et clique sur « Créer une partie ».
2. Il attend « Lien Internet prêt » dans son salon (quelques secondes ; au tout premier
   lancement, le jeu télécharge d'abord l'outil gratuit cloudflared de Cloudflare, environ
   50 Mo), puis clique sur « Copier le lien d'invitation » et envoie ce LIEN à son ami
   (Discord, SMS…). Le lien ressemble à : https://mots-au-hasard.trycloudflare.com/?code=ABCD
3. L'ami ouvre simplement ce lien dans son navigateur (Chrome, Edge, Firefox) : il arrive
   dans le salon. S'il a lancé son propre MafiaWars.exe, il peut aussi coller le lien dans
   « Rejoindre une partie ».

ATTENTION : le code de 4 lettres seul ne suffit pas. Chaque MafiaWars.exe fait tourner sa
propre partie ; le code n'existe que sur l'ordinateur de l'hôte. Il faut le LIEN.

Si le salon affiche « Lien Internet indisponible » (connexion de l'hôte qui bloque
Cloudflare) : le lien ne marchera que sur le même réseau (même box ou Wi-Fi). Pour jouer
à distance malgré tout : installez tous les deux un « réseau local virtuel » gratuit
(Radmin VPN, ZeroTier ou Tailscale) ; le salon de l'hôte affiche alors cette adresse sous
« Autres adresses », que l'ami colle dans « Rejoindre une partie » avec le code.
Sur le même réseau, si l'ami n'arrive pas à se connecter : l'hôte doit autoriser
MafiaWars dans le pare-feu Windows (« réseaux privés »).

BON À SAVOIR
- Navigateur conseillé : Chrome, Edge ou Firefox récent. Une carte graphique est
  recommandée ; sur un petit ordinateur, choisissez la qualité « Basse » dans les paramètres.
- Si le port 3000 est déjà pris, lancez le jeu avec un autre port depuis une invite de
  commandes :  set PORT=3001 && MafiaWars.exe
